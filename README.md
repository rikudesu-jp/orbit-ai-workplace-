# orbit-ai-workplace-
the ai workplace with every LLM model that you need for absolutely free just use your openrouter ai API to do that read "README.txt"

ORBIT — OPENROUTER AI WORKSPACE

1. Install Node.js 22 or newer on your machine: https://nodejs.org/
2. Rename .env.example to .env in this folder.
3. Create an OpenRouter API key at https://openrouter.ai/settings/keys
   Paste it after OPENROUTER_API_KEY= in your local .env file.
4. Open a terminal in this folder and run:

   node --env-file=.env server.mjs

5. Open http://127.0.0.1:3000 in your browser.
6. Choose a model in Explore models and send a message.
